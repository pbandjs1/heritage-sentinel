### Description

The goal of this project here is to create a small AI system which given a cultural heritage artifact:
 1. Assesses Damage
    - For example, a stone relief can have a loose base, a crack, or faded pigment
 2. Plans Restoration
    - Given the example of the stone relief, we can do things like stabilizing the base or sealing a crack, but some of these actions have prerequisites
 3. Tracks Provenance
    - TBD, but is the documented history of the object (ownership, location, and custody --> gives authenticity)
